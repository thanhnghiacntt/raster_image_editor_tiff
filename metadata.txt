qgisMinimumVersion=3.16
description=Đưa ảnh thường (PNG/JPG/TIF) vào bản đồ, kéo - xoay - co giãn để khớp đúng tọa độ rồi xuất ra GeoTIFF.
about=Plugin cho phép nạp một hoặc nhiều ảnh chưa có tọa độ lên canvas QGIS, chỉnh vị trí bằng cách kéo chuột (di chuyển, kéo bất kỳ điểm nào trên cạnh để co giãn riêng theo X hoặc Y, kéo góc để co giãn cả hai trục, xoay), hoàn tác/làm lại bằng Ctrl+Z và Ctrl+Y, hoặc căn chính xác bằng 2 điểm khống chế, hoặc nhập trực tiếp tọa độ tâm / kích thước pixel / góc xoay. Ảnh GeoTIFF / ảnh kèm world file đã có tọa độ được tự đặt đúng vị trí. Sau khi khớp, ảnh được xuất ra file GeoTIFF theo hệ tọa độ tùy chọn (EPSG:4326, EPSG:3857, VN-2000…) (kèm tùy chọn world file, nén, xoay về hướng Bắc, tạo overview), ghép nhiều ảnh thành một GeoTIFF, hoặc cắt thành bộ tile Web Mercator dạng thư mục z/x/y, ZIP hay MBTiles giống plugin QTiles.
version=1.2.0
changelog=1.2.0
  - Làm việc với nhiều ảnh cùng lúc: danh sách ảnh, chọn ảnh bằng cách bấm vào ảnh trên bản đồ, hiện/ẩn, đổi thứ tự chồng.
  - Xuất: ghép các ảnh thành 1 GeoTIFF, mỗi ảnh ra 1 file, hoặc chỉ ảnh đang chọn.
  - Hoàn tác / làm lại riêng cho từng ảnh; xuất tile từ tất cả ảnh đang hiện.
  1.1.0
  - Chọn hệ tọa độ cho file GeoTIFF xuất ra (EPSG:4326, EPSG:3857, VN-2000...), kèm nút nhanh Theo bản đồ / EPSG:4326 / EPSG:3857.
  - Nạp GeoTIFF, ảnh kèm world file hoặc có GCP thì tự đặt đúng vị trí và phóng tới ảnh.
  - Hỗ trợ ảnh 16 bit, ảnh bảng màu, nodata, file lưu từ dưới lên; ảnh trên 8000 pixel được đọc thu nhỏ.
  - File khác hệ tọa độ với bản đồ: tự quy đổi, hoặc hỏi chiếu lại / đổi CRS dự án / đặt gần đúng.
  - Sửa lỗi: đổi hệ tọa độ dự án khi đang có ảnh làm ảnh lệch khỏi chỗ.
  1.0.0
  - Phát hành đầu tiên.
